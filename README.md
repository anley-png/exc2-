# Excel Clone (Next.js 16)
## Setup
    npm install
    npx prisma db push
    npm run dev
## Status
Working: grid (windowed 52x1000), formula engine (~50 functions, ranges, errors, cycle detection), undo/redo, all 12 ribbon tabs, PDF export (pdf-lib).
Stubs (side-panel placeholders): charts, ink canvas, pivot, conditional formatting, xlsx import/export, Prisma persistence, WPS conversions.
## Shortcuts
Arrows/Tab/Enter move, F2 edit, Delete clear, Ctrl+Z undo, Ctrl+Y redo.
